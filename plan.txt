## 6. План разработки (обновленный для Go 1.25)

Теперь, когда у нас есть современная инфраструктура для Go 1.25, давайте скорректируем план разработки:

### Этап 1: Базовая инфраструктура (1 день)
- [ ] Настроить базовую структуру проекта с поддержкой Go 1.25
- [ ] Реализовать конфигурацию с Viper
- [ ] Настроить подключение к PostgreSQL с PostGIS
- [ ] Создать базовые миграции для таблиц
- [ ] Настроить логирование с zap/zap

### Этап 2: Сбор данных (2 дня)
- [ ] Реализовать парсер RSS-ленты с gofeed
- [ ] Создать сервис для получения деталей лота с torgi.gov.ru
- [ ] Реализовать получение cookies и данных с nspd.gov.ru
- [ ] Написать логику извлечения кадастрового номера и даты аукциона
- [ ] Реализовать сохранение данных в базу с поддержкой транзакций

### Этап 3: Планировщик и повторная обработка (1 день)
- [ ] Настроить cron-планировщик с поддержкой контекста
- [ ] Реализовать механизм повторной обработки ошибок с экспоненциальной задержкой
- [ ] Добавить health checks и graceful shutdown
- [ ] Настроить метрики и мониторинг

### Этап 4: Веб-сервер и API (2 дня)
- [ ] Создать Gin сервер с middleware
- [ ] Реализовать эндпоинт для кластеризованных данных с пространственными запросами
- [ ] Реализовать эндпоинт деталей лота
- [ ] Реализовать поиск по кадастровому номеру
- [ ] Настроить кэширование ответов

### Этап 5: Фронтенд (1 день)
- [ ] Создать базовый HTML/JS интерфейс
- [ ] Интегрировать Яндекс.Карты API
- [ ] Реализовать кластеризацию на карте
- [ ] Добавить popup с деталями лота
- [ ] Настроить адаптивное отображение

### Этап 6: Тестирование и оптимизация (1 день)
- [ ] Написать unit-тесты для критических компонентов
- [ ] Настроить интеграционные тесты с dockertest
- [ ] Оптимизировать запросы к базе данных
- [ ] Настроить кэширование и сжатие ответов
- [ ] Добавить мониторинг и алертинг

### Этап 7: Деплой и документация (1 день)
- [ ] Настроить GitHub Actions для CI/CD
- [ ] Подготовить Docker-образы для продакшена
- [ ] Написать подробную документацию
- [ ] Настроить автоматическое обновление

## Следующие шаги

1. Создайте папку проекта `lot-collector`
2. Разместите все файлы в соответствующих папках
3. Создайте папку `local-dev` и поместите туда файлы для локальной разработки
4. Инициализируйте git репозиторий
5. Запустите локальную среду с помощью `make dev-up`
